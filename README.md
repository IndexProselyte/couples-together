# Together

A Flutter prototype for a shared couples journal, with a mood dashboard,
relationship day counter, chat interface, customizable memory timeline,
light and dark themes, and an Android home-screen widget.

The application source is in `new_couples_together/`.

## Project status

This is a local prototype. Chat messages, timeline entries, and preferences are
stored on the device. The login screen does not authenticate users; remote chat,
encryption, social integrations, and notification delivery are not implemented.
The status indicators are demonstration UI.

New installations start with empty chat and timeline data. The relationship
counter defaults to today and can be changed in Settings.
